# Recruitment Assistant: исправление Transfer-Encoding

## Обновление существующего стенда (рекомендуется)
Завершите активные действия в интерфейсе. Сохраните резервную копию папки проекта.
Скопируйте файлы этого архива поверх исходников в прежней папке recruitment.
НЕ удаляйте существующие .env, deploy/secrets и Docker volumes.
Выполните: powershell -NoProfile -ExecutionPolicy Bypass -File .\UPDATE_WEB.ps1
Это пересобирает образ и пересоздает только web. Workers остаются на старом
образе до следующего штатного запуска; бизнес-код в этом исправлении не менялся.
Проверьте /health/live, затем изменение запроса и Продолжить через внешнюю ссылку.

## Чистая установка
Требуется работающий Docker Desktop (Linux containers).
Положите заполненный .env рядом с START_LOCAL.ps1; образец .env.example включен.
Запустите: powershell -NoProfile -ExecutionPolicy Bypass -File .\START_LOCAL.ps1
Python и Node на Windows не нужны. Для первой сборки нужен интернет.

ВАЖНО: имя Compose-проекта осталось recruitment-clean-v3-parallel.
На прежнем компьютере используются прежние volumes. Для них нужны прежние
файлы deploy/secrets. Только .env НЕ восстанавливает пароли существующей БД.
Не запускайте чистую установку из новой папки с новыми секретами поверх прежних
volumes: сначала сохраните и используйте существующий deploy/secrets.
Не используйте down -v и не удаляйте volumes.

## Временный внешний доступ
При установленном cloudflared запустите START_TUNNEL.ps1.
Ссылка меняется после нового запуска. Случайная ссылка не заменяет авторизацию.
Не публикуйте реальные резюме через незащищенный внешний стенд; используйте
согласованный с ИБ доступ и тестовые данные.

## Изменение
ASGI-адаптер удаляет транспортные Transfer-Encoding и Content-Length после
получения тела и задает фактическую длину буфера в байтах.
Старый HTTP-парсер, лимит 64 КиБ, владение задачами, бизнес-логика и 16/8 сохранены.

## Проверки
Синтаксис всех Python-файлов проверен. Шесть изолированных проверок реального
метода dispatch с реальным legacy JSON-парсером прошли: пустое chunked-тело,
русский запрос, устаревший Content-Length, неверный JSON, Content-Type и 64 КиБ.
Это не сквозная приемка: Docker/Windows/PostgreSQL/HH/ИИ/Gmail здесь не запускались.

## Секреты
Исходная TXT-выгрузка содержала действующие секреты. В архив они не включены.
Отзовите/замените раскрытые HH-токены и client secret, ключ ИИ, пароль приложения
Gmail. Ротацию паролей БД и browser/metrics secrets выполните согласованно с
конфигурацией существующих сервисов; простая замена файлов может нарушить доступ.
